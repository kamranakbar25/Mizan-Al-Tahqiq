# Master Database Schema — PostgreSQL Target

This is the target logical/physical contract. It is intentionally additive to the current schema. Exact Django migration files are not part of Phase 1.

## Common PostgreSQL conventions
- `uuid` for new globally stable cross-domain identities where appropriate; existing `bigint` PKs remain.
- `bigint GENERATED BY DEFAULT AS IDENTITY` corresponds to existing BigAutoField.
- `timestamptz` for event timestamps; UTC storage.
- `jsonb` only for variable metadata/engine output; core relationships are FKs.
- `text` for original scholarly text; do not constrain long Arabic/Urdu passages with arbitrary varchar lengths.
- `varchar(n)` for bounded codes/labels; use controlled lookup tables or CHECK constraints.
- `numeric` for precise numeric values; avoid floating point for audited quantities.
- `bytea` is not used for large source files; files live in private object/filesystem storage.

## A. Identity, bibliography and source

### `catalog_person`
`id uuid PK`; `canonical_name varchar(500) NOT NULL`; `name_ar varchar(500)`; `biography text`; `birth_date_text varchar(80)`; `death_date_text varchar(80)`; `birth_date_min date NULL`; `birth_date_max date NULL`; `death_date_min date NULL`; `death_date_max date NULL`; `identity_status varchar(24) NOT NULL`; `created_at timestamptz`; `updated_at timestamptz`.
Indexes: trigram on canonical name; normalized name lookup. Uncertain dates remain text/ranges.

### `catalog_person_name`
`id bigint PK`; `person_id uuid FK PROTECT`; `name_text varchar(500) NOT NULL`; `language varchar(16)`; `script varchar(16)`; `name_type varchar(32)` (kunya, nisbah, laqab, transliteration, variant, other); `is_preferred bool`; `source_citation_id uuid NULL FK`; `created_at`.
Index `(person_id, name_type)`, trigram on normalized name.

### `catalog_work`
`id uuid PK`; `canonical_title varchar(1000) NOT NULL`; `original_title varchar(1000)`; `transliterated_title varchar(1000)`; `subtitle varchar(1000)`; `work_type varchar(40) NOT NULL`; `primary_language varchar(16)`; `description text`; `status varchar(24) NOT NULL`; timestamps.
Indexes: trigram on title; full-text title/description where useful.

### `catalog_work_title`

### `catalog_work_contributor`
`id bigint PK`; `work_id uuid FK PROTECT`; `person_id uuid FK PROTECT`; `role_code varchar(40) NOT NULL`; `sequence integer NOT NULL DEFAULT 1`; `attribution_text varchar(500)`; `attribution_status varchar(24)`; `source_citation_id uuid NULL`; unique `(work_id, person_id, role_code, sequence)`. Role controlled vocabulary.

### `catalog_publisher`
`id bigint PK`; `name varchar(500) UNIQUE NOT NULL`; `location_text varchar(500)`; `website_url text`; timestamps.

### `catalog_edition`
`id uuid PK`; `work_id uuid FK PROTECT`; `publisher_id bigint NULL FK SET NULL`; `edition_statement varchar(500)`; `publication_year_text varchar(80)`; `publication_date_min date NULL`; `publication_date_max date NULL`; `publication_place varchar(500)`; `isbn varchar(40)`; `language varchar(16)`; `notes text`; `status varchar(24)`; timestamps.

### `catalog_volume`
`id bigint PK`; `edition_id uuid FK PROTECT`; `volume_number integer CHECK(volume_number > 0)`; `title varchar(500)`; `printed_page_start varchar(80)`; `printed_page_end varchar(80)`; unique `(edition_id, volume_number)`.

### `sources_source_record`
`id uuid PK`; `name varchar(500) NOT NULL`; `source_type varchar(40)`; `organization varchar(500)`; `source_url text`; `external_identifier varchar(255)`; `status varchar(24)`; timestamps. Index name/external identifier.

### `sources_acquisition`
`id uuid PK`; `source_record_id uuid FK PROTECT`; `document_id uuid NULL FK PROTECT`; `acquisition_method varchar(40)`; `acquired_at timestamptz`; `acquired_by_id bigint NULL FK SET NULL`; `supplier_text varchar(500)`; `accession_reference varchar(255)`; `transaction_reference varchar(255)`; `notes text`; `evidence_citation_id uuid NULL`; `created_at`.

### `sources_rights_record`
`id uuid PK`; `source_record_id uuid FK PROTECT`; `document_id uuid NULL FK PROTECT`; `rights_holder varchar(500)`; `rights_status varchar(32)`; `license_name varchar(255)`; `license_url text`; `license_version varchar(80)`; `permitted_uses jsonb`; `restrictions text`; `required_attribution text`; `territory varchar(120)`; `valid_from date NULL`; `valid_to date NULL`; `evidence_citation_id uuid NULL`; `created_at`; `created_by_id bigint NULL`.
Rights status values: unknown, public_domain, open_license, permission_required, restricted, proprietary, disputed, expired. Rights status is not scholarly authenticity.

### `sources_verification_event`
`id bigint PK`; `source_record_id uuid FK PROTECT`; `actor_id bigint NULL FK SET NULL`; `previous_status varchar(24)`; `new_status varchar(24) NOT NULL`; `rationale text`; `evidence_citation_id uuid NULL`; `created_at timestamptz NOT NULL`. Append-only.

## B. File and corpus

### `library_file_asset`
`id uuid PK`; `sha256 char(64) NOT NULL`; `byte_size bigint CHECK(byte_size >= 0)`; `media_type varchar(160)`; `original_filename varchar(500)`; `storage_backend varchar(40)`; `storage_key text UNIQUE`; `asset_role varchar(40)`; `retention_state varchar(24)`; `rights_record_id uuid NULL FK PROTECT`; `uploaded_by_id bigint NULL`; `created_at timestamptz`.
Index `(sha256, byte_size)`. Do not make SHA-256 unique at Document level; same bytes can have distinct source identity.

### `library_document`
Existing Document evolves additively: keep UUID id; `work_id uuid FK PROTECT`; `edition_id uuid NULL FK PROTECT`; `volume_id bigint NULL FK PROTECT`; `source_record_id uuid NULL FK PROTECT`; `file_asset_id uuid FK PROTECT`; `source_item_identifier varchar(255)`; `source_format varchar(20)`; `detected_language varchar(16)`; `script varchar(16)`; `page_numbering_system varchar(32)`; `metadata jsonb`; `status varchar(24)`; timestamps. Existing `book_id` retained during transition. Validate Work/Edition/Volume ancestry in a transaction/service.

### `corpus_content_unit`
`id uuid PK`; `document_id uuid FK PROTECT`; `unit_type varchar(32)`; `sequence integer`; `source_unit_label varchar(255)`; `pdf_page_index integer NULL`; `pdf_page_number integer NULL`; `printed_page_label varchar(80)`; `folio_label varchar(80)`; `width_points numeric(10,3) NULL`; `height_points numeric(10,3) NULL`; `rotation smallint`; `is_current bool`; `metadata jsonb`; unique `(document_id, unit_type, sequence)`.

### `corpus_text_version`
`id uuid PK`; `content_unit_id uuid FK PROTECT`; `version_number integer CHECK > 0`; `representation_type varchar(32)`; `language varchar(16)`; `script varchar(16)`; `direction varchar(8)`; `source_method varchar(32)`; `engine_name varchar(120)`; `engine_version varchar(255)`; `parent_version_id uuid NULL FK PROTECT`; `text text NOT NULL`; `text_sha256 char(64)`; `quality jsonb`; `review_state varchar(24)`; `created_by_id bigint NULL`; `created_at timestamptz`; unique `(content_unit_id, representation_type, version_number)`.
Representation types: raw_extraction, ocr_raw, corrected_transcription, normalized_search, transliteration, translation, editorial_text. Do not store all representations in one row.

### `corpus_text_block`
`id uuid PK`; `text_version_id uuid FK PROTECT`; `sequence integer`; `block_type varchar(24)`; `text text`; `language varchar(16)`; `bounding_box jsonb`; `structure jsonb`; unique `(text_version_id, sequence)`.

### `corpus_passage`
`id uuid PK`; `text_version_id uuid FK PROTECT`; `sequence integer`; `start_offset integer NULL`; `end_offset integer NULL`; `start_locator jsonb`; `end_locator jsonb`; `text_sha256 char(64)`; `segmentation_version varchar(80)`; `status varchar(24)`; unique `(text_version_id, sequence)`. Passage is version-bound.

### `corpus_review_decision`
`id uuid PK`; `text_version_id uuid FK PROTECT`; `reviewer_id bigint NULL FK SET NULL`; `status varchar(24)`; `notes text`; `resulting_text_version_id uuid NULL FK PROTECT`; `reviewed_at timestamptz`; `created_at timestamptz`. Append-only decision history.

## Required database invariants
1. Edition belongs to exactly one Work; Volume belongs to exactly one Edition.
2. Document's Work/Edition/Volume ancestry must be consistent.
3. Page index is zero-based; PDF page number is one-based; printed pagination is independent.
4. A TextVersion is immutable after publication; correction creates another version.
5. A Passage belongs to exactly one TextVersion.
6. A CitationLocator's passage and text version must agree.
7. An IsnadRoute has ordered IsnadLink rows with unique sequence.
8. Every hadith grade and narrator assessment has an assessor and source citation or an explicit documented reason for no citation.
9. Every Fiqh/Aqidah/Tasawwuf scholarly position is attributed and can coexist with conflicting positions.
10. Every vector embedding points to a specific passage and text version.
11. Verification/review/audit events are append-only.
12. No missing bibliographic field is populated by inference without an explicit attributed assessment.
